👻 snapgit

Create the GitHub App

For the person who runs this site, once. It registers one public GitHub App that anyone can use to sign in and install on their own repositories, so nobody else needs a token, a Vercel account, or an App of their own.

1. Register it

GitHub will show you the App (name, callback , permissions: Contents read and write, Pull requests read) and ask you to confirm. Nothing is created until you press the green button there.

App names are unique across GitHub. If snapgit is taken, pick another.

2. Put these in your host

Add them as environment variables (Vercel: Project, Settings, Environment Variables), then redeploy. The secret is shown here once and is not stored anywhere by this page.

GITHUB_CLIENT_ID
GITHUB_CLIENT_SECRET

3. Install it

Open the App's install page and choose the repositories you review in. Sign-in only reaches repositories where it is installed.
